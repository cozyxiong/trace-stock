# TraceStock

Circle（CRCL，纽约证券交易所，美元）的股价异动解释原型。页面包含日 K、事件时间线和可关闭的 Agent。

行情是一份本地日线快照，不是打开页面时的实时请求。交易日从上市后的第一个完整交易日 2025-06-06 起，到最近一个已完成交易日 2026-10-09 止。上市当日 2025-06-05 不在日期里。2026-10-12 的交易当时尚未结束，也没有收进快照。

事件只收录能指出来源的公开报道，并写成摘要。因果说法保持为假设。没有对应公开来源的异动日，页面不补原因。

## 文档对照

仓库里没有 `CONTEXT.md`、`AGENTS.md`、`CLAUDE.md`、术语表、ADR、代码规范或测试规范。实现遵循已经确认的规格 [Issue #1](https://github.com/cozyxiong/trace-stock/issues/1)，以及 [#2](https://github.com/cozyxiong/trace-stock/issues/2)、[#3](https://github.com/cozyxiong/trace-stock/issues/3)、[#4](https://github.com/cozyxiong/trace-stock/issues/4)。这些议题的原文没有改。

早期需求稿把 `relationType`、`exchangeTime`、`mappedTradeDate` 写在事件上，并把 `relatedEventIds` 写在异动上。已确认的规格改成：异动只由价格规则产生。纽约时间和映射交易日由带时区的发布时间、`America/New_York` 和交易日历计算，不手写。事实、观点、时间相关性、因果假设写在 Agent 结论上。事件详情里的相关性判断只说明时间归位，不把事件本身写成原因。

Issue #1 里的虚构一年日历，已经被这份公开日线快照替换。

## 异动规则

交易日就是快照里的已完成交易日。周末、全日休市、上市当日，以及快照没有给出的日期，都不会出现在日期条上。

涨跌幅是当日收盘价相对前一收盘价的变动，按远离零的方向保留两位小数。首个交易日 2025-06-06 没有前收盘价，不参与判定。绝对值达到 5.00% 记为异动；达到 8.00% 为显著，否则为中等。按这组收盘价，区间内有 126 个异动日。其中只有带来源的日期写了 Agent 记录，其余异动日显示「当前日期没有预设分析结果。」

快照里的价格和成交量都来自已完成日线，当前没有标成数据异常的交易日。不合法行情的页面分支仍留在代码里。

## 时间映射

交易所时区固定为 `America/New_York`，不读取浏览器时区。夏令时由这个 IANA 时区决定。2026-02-25 的业绩电话会显示 `-05:00`，2025 年 6 月和 2026 年 9 月的记录显示 `-04:00`。

常规时段是纽约时间 09:30:00（含）到 16:00:00（不含）。开盘前和交易时段内的事件映射到当天。16:00:00 及以后，以及周末、休市日，映射到日历里的下一交易日。没有下一交易日，或纽约日期早于 2025-06-06 时，结果是「超出数据范围」，不编造日期。

有的公开材料只写到日期。这类记录若用了整点，证据里会写明该时刻只用于放入交易日。

时间线只显示映射交易日属于选中日前一交易日、选中日、下一交易日的事件。同一映射日会标成时间关联，这句话只表示时间接近。

## 解释分类

Agent 使用随交易日取用的预设结论，不调用大模型。分数根据公开报道整理，不是统计概率。

- 事实：来源里直接写着的发布信息。
- 观点：本原型的预设结论里没有单独使用这一类。
- 时间相关性：映射日接近选中日，但不能推出影响。
- 因果假设：必须带「可能」，并写明证据、推理、置信度和其他解释。

如果一条因果假设引用的事件全部映射在异动日之后，且置信度高于 0.35，页面不会展示它。2026-09-03 和 2026-09-16 的材料不足以判断主要驱动因素。没有预设的异动日、普通交易日，都不编造驱动因素。

已收录的带来源日期包括：2025-06-18 的 GENIUS 表决、2026-02-25 的第四季业绩、2026-03-24 的稳定币收益草案、2026-06-30 的 Open USD、2026-09-02 的国会证词、2026-09-03 的上涨报道、2026-09-15 的 CLARITY 表决、2026-09-16 的 Arc 主网，以及 2026-10-06 的 OKX 融资报道。2026-10-06 和 2026-10-09 没有达到异动阈值，页面不给驱动因素。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。测试使用仓库里的日线快照，不访问外部行情。

```bash
npm test
```

测试打开页面，用交易日按钮、事件按钮和 Agent 结论切换内容，只检查页面上看得见的文字。K 线画布不作为点击目标。
